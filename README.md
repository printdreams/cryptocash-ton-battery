# Cryptocash Battery — TON

Backend service for the Cryptocash Battery on the TON network. This is the project skeleton: it boots an HTTP server, connects to Firebase (Firestore), and exposes a health check and a Firebase connection check. Business logic is added on top of this.

## Requirements

- Go 1.26.5
- A `.env` file in the project root with the Firebase service account credentials (already present):
  - `SERVICE_ACCOUNT`, `PROJECT_ID`, `PRIVATE_KEY_ID`, `PRIVATE_KEY_FIREBASE`, `CLIENT_EMAIL`, `CLIENT_ID`, `AUTH_URI`, `TOKEN_URI`, `AUTH_PROVIDER_X509_CERT_URL`, `CLIENT_X509_CERT_URL`, `UNIVERSE_DOMAIN`
  - Optional: `PORT` (defaults to `8080`)

The `.env` file holds secrets and is git-ignored.

## Setup

```bash
go mod tidy
go install github.com/swaggo/swag/cmd/swag@latest
swag init -g cmd/api/main.go
```

`swag init` regenerates the `docs/` package from the annotations. A minimal `docs/docs.go` stub is committed so the project also builds before the first `swag init`.

## Run

```bash
go run ./cmd/api
```

The server starts on `http://localhost:8080`.

## Endpoints

| Method | Path                | Description                                             |
| ------ | ------------------- | ------------------------------------------------------- |
| GET    | `/health`           | Liveness check; returns `{"status":"OK"}`.              |
| GET    | `/firebase/status`  | Verifies the Firestore connection with a live round-trip. |
| GET    | `/swagger/index.html` | Swagger UI ("Battery implementation for TON network"). |

## Project layout

```
cmd/api/           HTTP entrypoint (main)
internal/config/   .env / environment loading + Firebase credentials
internal/firebase/ Firebase Admin SDK initialization (Auth + Firestore)
internal/handler/  HTTP handlers and routing
docs/              Swagger spec (generated by swag)
```
